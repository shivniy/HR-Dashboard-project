# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an **HR Analytics Dashboard built using Microsoft Power BI** to analyze employee data and identify key workforce trends.

The dashboard provides insights into **employee attrition, salary, age, overtime, business travel, ethnicity, education level, department, gender, marital status, and employee distribution across states**.

The goal of this project is to transform raw HR data into an interactive dashboard that can help HR teams understand workforce patterns and make data-driven decisions.

---

## 🎯 Project Objectives

* Analyze overall employee demographics.
* Understand employee attrition patterns.
* Analyze attrition by age group, overtime, business travel, state, distance from home, and ethnicity.
* Compare employee counts across different categories.
* Analyze average salary and employee distribution.
* Identify workforce trends over time.
* Create an interactive HR dashboard using Power BI.

---

## 🛠️ Tools & Technologies
